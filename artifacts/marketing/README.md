# Abraxas X Launch Assets

Generated marketing video for posting on X (Twitter).

## Quick use

1. Upload **`abraxas-x-demo-9x16.mp4`** as the main post video (mobile-first vertical).
2. Set **`abraxas-x-demo-thumbnail.png`** as the custom video thumbnail in X composer.
3. Paste caption from **`X-POST-COPY.md`**.

Alternate: use **`abraxas-x-demo-16x9.mp4`** for desktop-heavy audiences.

## Regenerate

```bash
npm run marketing:x-demo
```

Requires Python 3, Pillow (`pip install pillow`), and ffmpeg.
