# Distribution — external install (Build #831)

## Gap addressed

Consumers must not depend on `file:../../packages/abraxas-independent-verifier` inside the monorepo.

## Supported install paths (no Abraxas app clone required)

### 1. Versioned tarball (default for design partners)

From a tagged Abraxas release or CI artifact:

```bash
npm install ./abraxas-independent-verifier-0.1.1.tgz
# integrity (example — verify against artifacts/npm/abraxas-independent-verifier-0.1.1.tgz.sha256):
shasum -a 256 -c abraxas-independent-verifier-0.1.1.tgz.sha256
```

In this repository, packed artifacts live under `artifacts/npm/` (generated by `npm run build831:pack-verifier`).

### 2. npm registry (founder-gated)

Package name: `@abraxas/independent-verifier`

Registry publication requires **founder authorization** (org scope, provenance, release controls). Until then, use the tarball only.

Do not publish from agent automation without explicit approval.

## Reproducible build

```bash
cd packages/abraxas-independent-verifier
npm ci
npm run build
npm pack --pack-destination ../../artifacts/npm
```

`prepack` runs `npm run build` automatically.
