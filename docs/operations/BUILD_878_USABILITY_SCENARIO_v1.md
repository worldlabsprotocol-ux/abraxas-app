# Build 878 — External usability scenario (minimal)

**Goal (read aloud once):**

> Use Abraxas to create a test application that can request and independently verify wallet-control decisions.

**Rules for facilitator**

- Do not provide step-by-step coaching.
- Record: completion (Y/N), assistance required, elapsed time, confusion points, whether the participant can explain how to integrate verification in their own app.
- Automated Playwright success is **not** a substitute for this session.

**Success signals**

- Participant stays in one workspace (no separate Integration Studio detour during guided flow).
- Participant distinguishes wallet demo proof from partner authorization.
- Participant reaches a sandbox application and understands the next step to put Abraxas in their app.

**Evidence to capture**

- Screen recording (desktop or mobile).
- Final route and application id (if created).
- Participant quote on integration vs testing.
